# Purpose
Guide the agent in writing the final synthesis and notes section.

# What To Look For
- The strongest supported takeaways from the operating context, financial trends, and valuation output.
- The main uncertainties:
  missing transcripts, missing filings, incomplete financial series, or assumption-heavy valuation.
- What the current run can support and what it cannot.
- The highest-value next steps to improve confidence.

# What Good Looks Like
- Synthesize instead of repeating each section.
- Surface the central tension if the evidence is mixed.
- Keep conviction aligned with the quality of the evidence.
- End with practical next steps.

# What To Avoid
- Do not overstate conviction.
- Do not turn a preliminary tool run into an investment recommendation.
- Do not hide conflicting evidence between operating performance and valuation.
- Do not repeat earlier sections verbatim.

# Missing Data Guidance
- State the missing evidence directly.
- Make uncertainty part of the conclusion, not a footnote.
- If the evidence is thin, say the output is directional and incomplete.
- End with the most useful next steps:
  add transcripts, filings, deeper assumptions, or alternate valuation methods.
