# Purpose
Guide the agent in judging whether residual income valuation is a good fit and how to interpret it when available.

# What To Look For
- Starting book value and the quality of shareholders' equity.
- Whether ROE appears durable, volatile, or distorted.
- The relationship between earnings power and book-value growth.
- Whether the business type is suitable for RIM:
  especially financials or firms where book value matters.

# What To Avoid
- Do not use RIM casually when book value is weak, distorted, or not economically meaningful.
- Do not assume ROE persistence without evidence.
- Do not ignore dilution, write-downs, or unstable equity-base effects.

# Missing Data Guidance
- If RIM is unavailable, say so plainly.
- If book value or clean earnings inputs are unreliable, state that RIM confidence is low.
- If the business is a poor fit for RIM, mention that rather than forcing the method.
